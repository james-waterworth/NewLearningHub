Learning Hub guidance

Learner guide

Find out how to enrol on training in ESR and keep your learning record up to date. Choose the guidance that matches what you need to do.

Before you start

You’ll need access to the Electronic Staff Record (ESR). Sign in using your usual ESR details, then follow the steps below. Course availability and enrolment are managed in ESR.

Choose a guide

Use your ESR learner homepage to find a course, choose a class and check that your enrolment has been recorded.

  1. Open My Learning

    On your ESR dashboard, select My Learning in the sidebar.

  2. Search for training

    Enter a keyword from the course name in the learner page search bar, then select the magnifying glass.

  3. Choose a class and enrol

    Select the course to see its available classes. Select the enrol cog for the class you want, review the details, add any special instructions and select Submit.

  4. Check your enrolment

    The course should appear under Instructor-Led Enrolments on your learning homepage.

Cancel an enrolment

Select the class name on your learning page. Choose Unenrol from the drop-down list and select Go. Choose a reason, then select Finish.

Managers and administrators can enrol staff through the team learning area in ESR. Check that you have selected the right staff member and class before submitting.

  1. Open team learning

    Select the Manager tab, choose My Team Career Information, then select Learning.

  2. Select the staff member

    Search by name or select the staff member from the list. Choose Action to open their learner page.

  3. Find and select the class

    Enter a course keyword in Search Course. Select the enrol cog beside the correct class.

  4. Submit and confirm

    Add any special instructions and select Submit. The course should appear under the staff member’s Instructor-Led Enrolments.

Cancel an enrolment

Select the class name, choose Unenrol from the drop-down list and select Go. Choose a reason, then select Finish.

Add learning completed outside the ESR course catalogue to your record. Your submission will be sent for approval before it is added to ESR.

  1. Open external classes

    In ESR, select My Learning, then select Manage my external classes at the bottom of the page.

  2. Start a new record

    Select Add to enter a new external class.

  3. Enter the course details

    • Start the title with LHD –, followed by the course name.
    • Choose the date of the Learning Half Day when you completed the course.
    • Enter the course supplier’s name.
    • Select Continue.

  4. Review and submit

    Check the details and who the request will go to for approval. Add any comments for the approver, then select Submit. Select Back if you need to make changes.

  5. Return to ESR

    After you see the submission confirmation, select Home to return to ESR.

Book the Self Directed Study Declaration from the Learning Hub catalogue to record learning you have completed independently.

  1. Open the Course Catalogue

    Go to the Learning Hub Course Catalogue.

  2. Find the declaration

    Scroll to the Course Prospectus and search for Self Directed Study Declaration.

  3. Book a date

    Select Self Directed Study Declaration to expand the course details, then select Book for the appropriate date.

  4. Sign in to ESR

    When redirected to the NHS Electronic Staff Record website, sign in with your ESR details.

  5. Select the date in ESR

    Select the enrol cog beside the date you want.

  6. Describe your learning and submit

    Enter details about your learning in Special Instructions, then select Submit.
